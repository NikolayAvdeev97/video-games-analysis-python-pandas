# Исследование рынка видеоигр (2000–2013)

## Описание проекта
Целью проекта является изучение развития игровой индустрии с 2000 по 2013 год для разработки стратегии привлечения старой и новой аудитории к игре «Секреты Темнолесья». 

В ходе работы проводится предобработка сырых данных, их категоризация на основе отзывов, а также выявление доминирующих игровых платформ на рынке.

## Стек технологий
* Python
* pandas

## Основные этапы работы
1. **Предобработка данных**: Названия столбцов приведены к нижнему регистру и стилю `snake_case`, типы данных оптимизированы (перевод текстовых жанров и рейтингов в формат `category`). 
2. **Работа с пропусками**: Пропуски в данных о продажах заполнены средними значениями по группам (платформа + год релиза). Отсутствующие оценки пользователей и критиков заменены на метку-индикатор `-1`. 
3. **Очистка от дубликатов**: Устранены неявные дубликаты в жанрах и устаревший возрастной рейтинг K-A. С помощью сортировки обнаружено и удалено 235 полных дубликатов строк.
4. **Фильтрация и категоризация**: Сформирован срез данных за актуальный период (2000–2013 гг.). Игры сегментированы на группы («Высокая оценка», «Средняя оценка», «Низкая оценка», «Нет оценки») в зависимости от баллов критиков и пользователей.

## Главные выводы
* После проведения группировки выяснилось, что подавляющее большинство выпущенных игр имеют средние или высокие оценки, либо не имеют их вовсе (более 5000 игр без оценок). 
* Выделен топ-7 платформ по количеству изданных игр за исследуемый период: PS2 (2127 игр), DS (2120), Wii (1275), PSP (1180), X360 (1121), PS3 (1087) и GBA (811). Именно эти платформы доминировали на рынке и охватывали основную базу игроков.
